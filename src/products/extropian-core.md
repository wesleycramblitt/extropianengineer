**Extropian Core** is the shared foundation of the ecosystem: the C++ libraries every other Extropian component composes. It is open source under Apache 2.0 so teams can build their own software on the same primitives the products use.

Everything else in the ecosystem — Geometry, CAE, Physics, Render, Spatial UI — is built on Core and available as modular repositories that drop into your own codebase.
