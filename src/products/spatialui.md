Most engineering software lives with a split personality: a native or DOM-based UI bolted onto a graphics engine. Extropian Spatial UI eliminates that divide by drawing the 2D interface directly inside the GL context — lightweight, performant, and deployable anywhere a GL context runs.

That makes it the interaction foundation for engineering tools that need UI and visualization to behave as one system.
